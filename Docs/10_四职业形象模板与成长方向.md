# 四职业形象模板与成长方向

版本：v0.2；日期：2026-09-17；状态：定位已按用户反馈修订，具体数值与技能待校准。

本版替代 v0.1 的每职业三个特色模板方案：每职业一个平庸模板、两个优秀模板，共十二个。大部分获取结果为平庸模板；普通渠道“平庸80%、优秀20%”为此前接受的初始概率草案，按渠道配置，已落入本地草稿，尚未发布。

## 1. 模板、资质与获取

- 职业决定技能体系与可选进阶路线；模板决定形象、成长底子和战斗方向；灵根独立决定资质倍率；实例保存独立姓名、培养经历与状态。
- 平庸模板是获取主体，拥有完整培养、装备与进阶能力，但没有优秀模板的突出成长专长。好灵根的平庸模板仍有培养价值。
- 优秀模板在指定方向上有优势，同职业两个优秀模板各有取舍，不做彼此全面替代。普通与优秀的划分属于修士模板获取分类，与物品六个品级无关。
- 姓名不用于索引模板。同模板可生成不同姓名；姓名创建时抽取一次并保存，初始队伍固定姓名优先。
- 后台使用“普通 / 优秀”分类；玩家端展示“行脚禅修”等具体名称，不直接标注“平庸”。
- 普通渠道先确定职业，再按该职业模板权重抽取。初始建议普通80%，两个优秀各10%；职业权重、渠道与实际投放入口单独配置，不能由此推断四职业必然各25%。特殊渠道可指定模板或调整权重。
- 随机模板获取是新增设计范围。首期仍保留石岩、陆清、白灵、墨言四名初始实例配置；固定四人不参与上述抽取。未来获取渠道、消耗、容量、重复获取与事务实现需另行补齐。

## 3. 优秀模板的技能方向

以下为技能设计约束，未配置为现有可执行技能。属性成长不能自动产生治疗、抗性增益、嘲讽或攻击频率变化。正式阶段仍遵守每职业阶段三个主动技能，不额外叠加模板专属主动技能槽。

### 禅修：防御与输出

- **金刚禅修**：以自身减伤、护体或保护队友为主要技能方向；力道仍为中上，但伤害系数与成长不能达到降魔的输出水平。
- **降魔禅修**：以力道伤害、重击与持续近身输出为主要方向；可保留基础自保，不同时拥有金刚级防御覆盖。
- 与护阵符修区别：金刚依靠更强自身承伤承担持续前线；护阵以主动吸引攻击和有限治疗保护队伍。二者都能保护队友，但护阵不应同时达到金刚承伤与济世治疗的峰值。

### 法修：输出与干扰辅助

- **五行法修**：三个技能围绕单体、群体或爆发法术伤害安排；元素表现可丰富，但不据此新增元素克制规则。
- **幻术法修**：三个技能围绕降低敌方威胁、打乱行动或限制目标安排，保留一个基础伤害手段。具体采用何种干扰状态需核对战斗引擎，再配置命中、持续时间与冷却。
- 幻术不能通过高伤害技能系数同时成为最强法术输出，也不承接符修的主治疗职责。

### 符修：治疗加抗性与防御嘲讽兼治疗

**济世符修建议三槽：**

1. 定向治疗：处理主要受伤目标。
2. 群体或持续治疗：维持全队血线；具体形式待技能能力核对后确定。
3. 抗性增益：提高目标或队伍的抗性，需明确实际作用的伤害或状态类型。

**护阵符修建议三槽：**

1. 嘲讽：让符合条件的敌方攻击优先指向自身。
2. 防御：自身护盾或减伤，覆盖嘲讽后的承伤窗口。
3. 辅助治疗：低于济世的治疗能力，用于应急维持自身或队友。

设计边界：

- “抗性增益”是施加给受益对象的技能效果，不等于只提高济世自身的定力。
- 抗性具体影响法术伤害、控制效果还是其他状态，必须与正式战斗公式对齐，不能宣称对所有伤害和异常一律有效。
- 嘲讽需定义合法目标、持续时间、覆盖/刷新、免疫、施法者阵亡后的解除规则，以及是否影响已经锁定的攻击。群体伤害不应被单体嘲讽无条件吸收。
- 治疗量、治疗频率、护盾和减伤要有预算约束，不能让护阵形成无限自疗承伤。

### 剑修：高频轻击与低频重击

- **疾风剑修**：速度成长突出，攻击间隔短；基础攻击和主要输出技能的单次伤害中低。速度必须体现为真实出手频率，不能只改变排序或面板数值。
- **重岳剑修**：力道成长突出，攻击间隔长；单次伤害高。不能只提高力道而仍保持疾风的攻击频率。
- 在同等级、同灵根、同装备预算下，先以持续输出接近为校准起点，再通过目标血量、减伤规则和战斗长度体现区别。
- 近似持续输出 = 单次有效伤害 / 实际攻击间隔；实际还需计入技能、命中、目标死亡和动作占用。例：疾风60伤害/1秒、重岳150伤害/2.5秒，理论均为60/秒，只是便于说明的示意，不能直接当正式配置。
- 高频触发的附加效果、固定伤害、吸血等需单独验算；禁止因按次收益未经限制而让疾风在所有场景全面领先。重岳需检查过量伤害、起手被打断和目标转移造成的损失。

## 4. 成长与能力预算

| 优秀模板 | 主成长 | 次成长 | 限制方向 |
| --- | --- | --- | --- |
| 金刚禅修 | 肉身、护体 | 力道中上、定力 | 遁速与输出系数 |
| 降魔禅修 | 力道 | 肉身 | 护体与防御技能覆盖 |
| 五行法修 | 法力 | 神识 | 肉身、护体 |
| 幻术法修 | 神识 | 遁速、法力 | 直接伤害与治疗 |
| 济世符修 | 治疗相关主属性（拟法力） | 定力、神识 | 肉身、护体与直接伤害 |
| 护阵符修 | 肉身、护体 | 定力、适量法力 | 治疗系数、遁速与输出 |
| 疾风剑修 | 遁速 | 神识、适量力道 | 单次伤害系数、肉身 |
| 重岳剑修 | 力道 | 肉身、护体 | 遁速、攻击频率 |

普通模板沿用各职业基础倾向，成长整体普通，不应靠平均分配后在所有实战场景胜过优秀模板。不同灵根允许实力交叉，不能保证“优秀模板任何时候都强于普通模板”。

后台已有的七维倍率继续使用：每级成长 = 当前职业千分成长 / 1000 × 模板千分倍率 / 1000 × 灵根百分比 / 100。此公式只处理属性成长，不能替代技能系数、攻击间隔和状态规则。

档位和倍率不统一硬映射。需在 Lv10、20、30、两条进阶路线及不同灵根下验算；不能用减少无用属性交换大量核心属性，也不能只按七维总和判断平衡。

## 5. 进阶路线与现有实现的衔接

| 模板方向 | 当前推荐路线 | 需要补齐的内容 |
| --- | --- | --- |
| 金刚 | 护法金身 → 不动金刚 | 防御和保护技能 |
| 降魔 | 魔相力士 → 三相魔君 | 力道输出技能 |
| 五行 | 雷法术式 → 九霄雷君 | 法术输出技能 |
| 幻术 | 蜃景幻法 → 蜃梦玄君 | 干扰状态及技能 |
| 济世 | 镇幽符脉 → 镇魂符君 | 采用17分册安魂回元箓的群疗与定力增益；用户已确认作为治疗方向基础 |
| 护阵 | 万象符脉 → 天元符君 | 防御、嘲讽与辅助治疗技能 |
| 疾风 | 青冥剑修 → 青冥剑君 | 攻击频率与低单次伤害配置 |
| 重岳 | 玄岳剑修 → 玄岳剑君 | 慢速与高单次伤害配置 |

继续允许同职业模板选择两条路线，推荐不等于限制。平庸模板也可走两条路线。跨方向进阶形成混合培养，必须预览实际属性与技能，而非保证模板标签在任意路线下都是最终战斗定位。

当前模板只有成长倍率、形象与姓名等配置，同职业炼气阶段共享职业技能；因此只能先体现数值倾向，无法完整体现两套符修技能。完整落地前需扩展“模板引用技能方案”，炼气仍使用三个槽；筑基后由所选路线的三技能方案接管。该引用、方案编辑和发布校验属于待开发内容，不能仅靠修改显示名称完成。定力/神识/速度实际作用也需核对现有战斗公式。

## 7. 实施与验收

1. 配置模型增加普通/优秀分类与渠道模板权重；补四个普通模板、幻术、护阵、重岳，共七个新模板，调整现有符修和剑修定位。
2. 校准十二模板的成长与攻击节奏，绑定形象；完成模板技能方案引用、引用校验及编译输出。
3. 补齐治疗、抗性、嘲讽、干扰技能与服务端/C端一致的战斗规则；校准既有路线。
4. 独立实现获取流程、实例初始化与成长账本，再接 C 端。初始固定四人不受概率影响。

验收：

- 模板总计12个，每职业1普通、2优秀；没有第三优秀方向。
- 按渠道的大样本获取结果符合配置权重，不将80%理解为每十次必有八个普通。
- 金刚承伤优于降魔，降魔输出优于金刚；五行直接伤害优于幻术，幻术具备真实干扰作用。
- 济世治疗强于护阵且能施加抗性增益；护阵能有效嘲讽并承受相应压力，具有较弱但可用的辅助治疗。
- 疾风实测出手次数更多、单次伤害中低；重岳出手更慢、单次伤害更高。
- 普通模板完整可用，好灵根普通模板有培养空间；优秀模板不靠额外技能槽形成优势。
- 同模板不同姓名合法，既有实例不重算；草稿未发布时 C 端状态不变。

当前已完成12模板后台草稿、普通/优秀分类、默认渠道权重及成长倍率初值。多渠道获取事务、模板技能方案与实际战斗效果尚未实现。

### 用户补充确认：符修技能沿用文档基线

用户确认两个方向分别重治疗、重防御嘲讽，并接受17分册现有技能作为基础：治疗线使用群疗加定力，防御线使用单疗加护体、力士符傀嘲讽。不因模板名称重新设计一套技能，也不擅自把原文符傀承担嘲讽改成符修本体承担。仍按三个阶段技能和原文筑基/结丹数值导入，遵守后续用户新调整优先。
