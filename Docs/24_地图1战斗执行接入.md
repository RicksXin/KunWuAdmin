# 地图1战斗执行接入

日期：2026-09-18。配置集 `v1_0` 修订209；开发发布版本仍为 `dev-r4-5`。

## 已完成

- 复用 Godot 现有地图1战斗实现，将14个敌人技能、8种敌人的执行参数及技能绑定以审计事务入库。新增 `skill.enemy_runtime` 和 `enemy.runtime`；重复同步0变更。
- 后台技能列表分开显示玩家技能与敌人技能；敌人详情展示已录入的护盾、反震、光环及Boss阶段参数。
- 远端适配保留状态效果、条件技能、预警、初始行动时间、被动和Boss阶段；完整覆盖正式遭遇ID的远端战斗表不再被地图迁移回退覆盖。未完整覆盖时仍回退内置配置。
- 首杀、重复魂晶与固定物品分别适配。胜利结算保存 `encounterSettled`，重载或重复回调不再次发奖；同次出征不能重开已完成遭遇。新出征仍使用原有首杀记录判断重复奖励。
- 存档写入检查实际错误，直接原子重命名替换，不先删除旧档；领取待处理战利品保存失败时恢复内存状态。
- 修正石甲守卫满血也会轮到护盾的选择问题；Boss35%阶段仅加速裂地震，不加速所有技能。执行根系控制免疫、100%/60%/30%眩晕递减和16tick裂地震预警。
- 新规则计算放入 `KWCombatResolver`，场景负责调用、计时与表现，不另建战斗系统。
