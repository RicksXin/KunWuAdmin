# 怪物美术复用方案

依据用户最新确认：收口怪物美术类型，高阶怪复用模型并以特效、材质和滤镜区分。此方案覆盖38条敌人配置，不删减战斗角色、名称、数值或70组遭遇。

## 预算与制作边界

- 基础模型控制为6套，精英不新增独立模型或骨架。
- 四个Boss复用对应族基础模型，另计冠饰、魂旗、核心、双附加臂和银翼等模块；不是仅做6个文件就全部完成。
- 每族共用待机、移动、攻击、受击、死亡动作；Boss特殊动作和部位绑定另计。
- 普通怪以局部配色和材质区分；精英加符纹与精英标记；Boss增加必要部件与阶段特效。避免全屏滤镜、过多粒子遮挡战斗。
- 不能只靠颜色表达危险：精英标记、技能预警和目标名称必须保留。缩放不改变命中区域与战斗数值。
- 美术家族与生物种族、伤害抗性无关；同模型不意味着同技能。名称仍采用已有策划，特殊外形通过低成本轮廓部件表达。
- 当前仅是模型引用与制作规划，没有生成模型、贴图或特效，也未接入Godot加载器。

## 落地顺序

1. 先制作人形、构装体、灵体，验证普通/精英共用动画与材质变体。
2. 补齐灵兽、植物、器物三套，逐一确认同场敌人可辨认。
3. 在基础模型稳定后制作Boss挂件、部位命中区域与特殊动作。
4. 最后接入模型资源路径、LOD与特效池；手机端同场4敌人进行性能实测。
