# 地图1遭遇、装备与结算闭环

2026-09-18，v1_0 修订211。开发快照已同步 Godot，未发布渠道版本。

## 已实现

- 13组新版遭遇绑定正式地图入口，保留洞窟剧情战，共14个入口。地图坐标和美术不变。
- Boss首次胜利生成法器1件、真宝1件；实例ID、模板和属性使用稳定种子，重复结算不会重抽或重复发放。已领取旧版首杀的存档不自动补发。
- 战利品先进入出征临时装备，归营后入库。仓库满时暂存，整理容量后补入；离开战利品界面仍保留指定装备和任务物。
- 百宝库 → 装备管理可查看、穿戴、卸下和丢弃装备；职业限制与占用校验生效，重复穿戴不会叠加属性。已穿戴、锁定或保护装备不能丢弃。
- 阵亡对本次临时材料按30%向上取整扣除；临时装备逐件以稳定种子判定30%损失。带入物品和保护任务物不参与该损失。归营存档失败会回滚内存，结算重试不复制奖励。
- 后台战斗配置增加入口、装备模板和Boss奖励只读表。敌人和技能实际数值由数据库表装配，避免另维护一套数值。

## 首版数值与边界

初始池6个武器/护甲模板；预算10或12，每件2个属性槽，法器预算倍率100%、真宝120%。这是本轮可调整的初始数值，尚未经平衡验收；不是旧精制/上品的映射。六品级命名不变，目前Boss只生成前两级。

模板与装备池放在 `server/domain/encounters/map01-loop.json`，开发同步命令 `pnpm map01:loop:sync`。对已有配置差异拒绝覆盖，修改需要明确迁移。当前未提供模板数值表单编辑器。装备临时栏独立于材料负重，本轮未实现装备重量；饰品槽结构已保留，但初始池没有饰品。

数据库 `game_parameter.map01_loop` 保存运行规格；编译时从敌人/技能表装配实际字段。开发同步显式允许尚未启用的敌人导出本地快照，正常校验和发布编译禁止这样做。Godot内置快照是开发验证产物，不代表远端频道更新。
